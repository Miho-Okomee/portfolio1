デザインシステム自動継承

ブランドの色・フォント・コンポーネントを読み込ませるだけで自動適用。毎回バラバラになる問題を解決。

  • スクリーンショット・画像をアップロード
  • Figmaファイルやコードリポジトリを参照
  • DOCX / PPTX / XLSX もインポート可
💬

チャット ＋ インライン編集

大きな変更はチャットで、細かな調整はキャンバス上のインラインコメントで。バージョン管理も内蔵。

  • 「ヘッダーのレイアウト変更して」→ チャット
  • 「このボタンのパディングを大きく」→ インライン
  • 現在の状態を保存して別アプローチも試せる
📤

多彩なエクスポート ＆ 引き継ぎ

実務で使える形式に変換。Canva連携でさらに磨き、Claude Codeへ渡して実装まで完結。

この学習ロードマップでの Claude Design 活用イメージ

Phase 1 Material Design などの既存DSをClaude Designに読み込み、どう解釈するか見て学ぶ。基礎の理解が直感的になる
Phase 2 Atomic Designを学びながら、実際にClaude Designでコンポーネントを試作。設計思想と出力結果を比較する
Phase 3 エクスポート機能（HTML / PPTX）を使い、Storybookと比較。ツールの使い分けを体感しながらトークン設計を深める
Phase 4 このポートフォリオにClaude Designで作ったモックアップを適用 → Claude Code に引き継いで実装。ワークフロー全体を体験する
⚠️ 現時点の制限（研究プレビュー段階）
  • インラインコメントが消失する場合がある
  • 大規模なコードベース読み込み時にラグが生じることがある
  • 細かなレイアウト調整はFigmaには及ばない（プロトタイプ初期段階として活用するのが現実的）

2時間/日を効果的に使うコツ

1
最初の30分はインプット（読む・見る）、残り90分は手を動かす。読むだけでは身につかない。
2
このポートフォリオのCSSを改善しながら学ぶ。既にCSS変数が使われているので、実践しやすい。
3
Material Design などの実際のDSを「写経」する。なぜそのトークン値にしたか考えながら。
4
週末は振り返りと整理の時間に。ノートやFigmaでその週の学びをまとめることで定着する。
